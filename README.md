💊 Medicon System

Medicon System is a full-stack Medication Management Platform built using Spring Boot, React.js, and MySQL.
It helps users efficiently manage their medications, set smart reminders, and ensure treatment adherence through real-time tracking and automated email notifications.



🚀 Features

🩺 Medication Management – Add, update, and delete medication details easily.

⏰ Smart Reminders – Get automatic email reminders for upcoming doses.

📊 Real-Time Tracking – Monitor medication schedules and progress in real-time.

💬 Email Notifications – Sends timely alerts to ensure no dose is missed.

🔗 RESTful APIs – Built with Spring Boot and Spring Data JPA for smooth backend operations.

🖥️ Responsive UI – Intuitive and user-friendly interface built with React.js.
